# 三层五子棋

## 运行

**最简单：** 双击 `开始游戏.bat`（会自动装依赖、开服务器、打开浏览器）。

或手动：

1. 安装 Node.js 18+
2. `npm install`
3. `npm start`
4. 主机与队友浏览器打开终端里打印的局域网地址
5. 一人「创建房间」，一人「加入房间」

关闭黑色命令行窗口即停止游戏。

## 公网分享

启动后，服务器会自动下载并运行 Cloudflare Quick Tunnel，在终端打印 `Public` 邀请链接。复制链接发给好友即可，好友无需安装软件或在同一局域网。

首次下载需要访问 GitHub；如果下载受限，可手动把对应平台的 `cloudflared`（Windows 为 `cloudflared.exe`）放进 `bin/` 后重新启动。关闭命令行窗口会同时停止公网链接。

## 说明

- 静态页面：`public/`
- 共享规则：浏览器通过 `/shared/*.js` 访问 `shared/`
- WebSocket 与 HTTP 共用同一端口（默认 3000）
- 堆叠移动规则：只能移动顶层棋子，目标高度须在起始高度 - 1 到起始高度之间。
