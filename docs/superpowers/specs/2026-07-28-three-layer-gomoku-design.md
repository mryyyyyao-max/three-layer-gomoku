# 三层五子棋 — 局域网双人原型设计

日期：2026-07-28  
状态：已实现原型

## 目标

做一个**最小可玩**的浏览器局域网双人对战原型：两人连上、按规则下完、能判胜负。

非目标（本原型不做）：账号、观战、AI、本机热座、断线重连、多房间大厅、精美动画。

## 技术选型

- **方案**：单页前端 + Node.js HTTP/`ws` 服务端（服务端权威）
- **启动**：`npm start`，终端打印局域网地址（如 `http://192.168.x.x:3000`）
- **联机**：同一 Wi‑Fi 下两人打开该地址；一人「创建房间」，一人「加入房间」

## 架构

```
浏览器 A / 浏览器 B
        │  WebSocket
        ▼
   Node 服务端
   - 房间状态机
   - 规则校验（布局/放置/移动/胜负）
   - 广播同步后的 gameState
```

- 客户端只负责渲染与发起意图（place / move / selectAction）
- 非法操作由服务端拒绝并返回错误文案，不换手

## 联机流程

1. A 打开页面 →「创建房间」→ 先手（深色棋子）
2. B 打开同一地址 →「加入房间」→ 后手（浅色棋子）
3. 两人到齐 → 布局阶段 → 行动阶段
4. 胜负达成 → 展示结果与胜法 →「再来一局」同房重置到布局

房间模型：单机单房间即可（原型）。第二人加入后锁定；满员后禁止第三人。

## 棋盘

- 形状：点朝上？否 — **平顶正六边形**三角网格（对齐项目内参考图）
- 规模：每边 **4** 边长的六边形，再去掉六个尖角交点（缺角，对齐参考图）→ **55** 个交点
- 落子点：网格**交点**（顶点）
- 坐标：轴向坐标 `(q, r)`，三方向用于连线判定（水平 / +60° / −60°）
- 正中心：`(0,0)`；布局阶段禁止落子
- 六个缺角尖端：`(±4,0)`、`(0,±4)`、`(4,-4)`、`(-4,4)` 不在棋盘上

视觉：深色底 + 白线；矩形外框可选；棋子为深/浅圆柱简绘，叠放时可见层数。

## 棋子与堆栈

- 每人手中 **25** 枚
- 每个交点是一个堆栈，高度 **0～3**
- 堆栈自下而上记录所属玩家
- **俯视五连**只看每格**最顶层**颜色
- 移动时只能移动某堆中**属于自己且位于可动位置**的棋子；原型约定：**只能移动该堆最顶层且属于自己的棋子**（顶层是对方则不可从该格移出）

## 布局阶段

落子顺序（共 6 枚）：

| 步序 | 玩家 | 本步枚数 |
|------|------|----------|
| 1 | A | 1 |
| 2 | B | 2 |
| 3 | A | 2 |
| 4 | B | 1 |

约束（仅布局）：

1. 不可放在正中心
2. 不可放在与**己方已有棋子**相邻的交点（六邻域）
3. 只能放在空位（高度 0）
4. 本步需连续放完规定枚数后再换手

布局结束后进入行动阶段；中心点此后可落子/移动占用。

## 行动阶段

轮到自己时二选一（先点模式按钮，再点棋盘）：

### A. 放置

- 手中剩余 > 0
- 目标为空位
- 无「邻己」「禁中心」限制

### B. 移动

- 选中己方可移动棋子（堆顶且己方）
- 移动到**相邻**交点（一步）
- 可叠在敌我棋子上
- 移动后目标堆高度 ≤ 3

**叠放裁决（原型写死）：**

记 `destH` = 目标堆当前高度。

1. **`destH < 3`**（可叠到二层上变成三层；不可再叠到已满三层）
2. 相邻两层棋可以互相叠成三层（与实玩反馈一致；不再限制起始层级）

实玩若不符，只改叠高上限，不改架构。

## 胜负（三选一，先达成者胜）

检查时机：每次合法**放置**后检查落子方；每次合法**移动**后先检查移动方、再检查对手（任一方达成即终局）。

### A. 俯视恰好五连

- 仅统计各格顶层颜色
- 沿三方向，连续恰好 **5** 个同色顶层即胜
- **6 连及以上该线段不构成胜利**（多连不行）

### B. 第三层五枚

- 统计：所有高度为 3 的堆中，**第 3 层（顶层）为己方**的交点数量 **≥ 5**
- 位置不限

### C. 第三层三枚相邻

- 在上述「己方第三层」交点集合中，存在大小 **≥ 3** 的连通块（六邻接）

平局：本原型不实现专项判和；可用「再来一局」手动重开。

## 界面

- 首页：创建房间 / 加入房间；创建后显示等待与访问地址提示
- 对局：阶段文案、当前玩家、双方剩余手棋、放置/移动按钮
- 非法：旁路短错误提示
- 结束：胜者 + 胜法标签 + 再来一局

## 风险与待实玩确认

1. 移动条件按「目标堆高 ≤1 且 ≤ startLevel」理解原文；若你本意不同，实现前改两行即可  
2. **五连**：整段同色顶层长度必须**恰好为 5**（6+ 不胜）  
3. **第三层五枚**：按 **≥ 5**

## 验收标准

- [x] 两人能用局域网 IP 加入同一局
- [x] 布局 6 步约束正确（中心、邻己）
- [x] 放置与移动（含叠层上限与禁叠二层）可用
- [x] 三种胜法至少各能在手动构造局面下触发一次
- [x] 再来一局可回到布局
