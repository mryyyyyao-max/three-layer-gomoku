# 快捷嘲讽气泡 · 悔棋求饶 · 终局复盘

日期：2026-07-28  
状态：实现中

## 目标

1. **嘲讽气泡**：左右区两个固定文案按钮，点击后双方屏幕飘出气泡（上浮淡出），可连点。  
2. **悔棋求饶**：点悔棋 → 双方看到「求你啦爸爸让让我😭」→ 对方「同意」→ 真撤一步。  
3. **终局复盘**：仅 `ended` 后可拖进度查看每一步（只读预览）。

## 非目标

- 自由聊天输入、同意以外的「拒绝」专用协议（可点别处关掉请求）  
- 对局中复盘改盘、一次悔多步协商

## 协议

- `taunt` `{ text }` → 广播 `{ type:'taunt', text, from }`（白名单两句）  
- `undoRequest` → 广播 `{ type:'undoPlea', from }`  
- `undoAccept`（仅对方）→ 弹出历史一步，广播 `state` + `{ type:'undoDone', by }`  
- 每步成功 `place`/`move` 后压入上一局面快照；`start`/`restart` 清空历史与 plea  
- `ended` 的 `state` 附带 `replay: GameState[]`（含逐步快照 + 终局）

## UI

- 宽屏：左嘲讽 | 棋盘 | 右嘲讽；窄屏嘲讽在棋盘下  
- 气泡：CSS 动画上浮淡出  
- 悔棋按钮在状态栏；plea 浮层双方可见，对方多「同意」  
- 终局：进度条 + 步数，拖动切换本地预览帧
