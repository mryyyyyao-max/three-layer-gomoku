# 规则页（图示循环演示）设计

日期：2026-07-28  
状态：待实现

## 目标

为三层五子棋提供**可图示理解**的规则页：用与真游戏一致的迷你棋盘做**自动循环动画**，避免纯文字。  
大厅与对局中均可打开；页面可独立分享（`/rules.html`）。

## 非目标

- 可交互「自己试下」沙盒
- 多语言、外挂 GIF/视频素材
- 修改对局规则本身（演示以已定规则为准，含叠层统一公式）
- 左栏目录版式（已否决；采用纵向滚动）

## 决策摘要

| 项 | 选择 |
|----|------|
| 入口 | 大厅 + 对局均可进（打开规则页，带回链） |
| 演示形式 | 循环小动画（非纯静态、非点播优先） |
| 内容范围 | 完整版七章（棋盘→布局→放置→叠层→三种胜法） |
| 实现 | 复用 `render.js` 的迷你 Canvas |
| 版式 | 纵向章节滚动 |

## 页面结构

- URL：`/rules.html`
- 顶栏：标题「三层五子棋 · 规则」+ 「返回游戏」（链到 `/` 或 `document.referrer` 合理回退）
- 主体：七个 `<section>`，每节含：
  - 短标题
  - 一句说明（中文）
  - 一个 `<canvas>` 迷你棋盘（自动循环）
- 可选：节末极短补充（如「六连不胜」），仍以动画为主

视觉：延续游戏页气质（暖色底、深浅圆柱），不另起一套插画风。

## 章节与演示脚本

每段约 **4–8 秒**循环；进入视口播放，离开暂停。

1. **棋盘与棋子**  
   展示六边形点位；深/浅圆柱；同一交点叠高 1→2→3。

2. **布局阶段**  
   按 A1→B2→A2→B1 落子；尝试中心或邻己时红闪/短暂拒绝示意，再回到合法落子。

3. **行动：放置**  
   行动阶段向空位（含中心）落子。

4. **行动：移动与叠层**  
   合法：一层叠一层、二层叠二层成三；  
   非法：一层上二层、二层落空地、三层落空/一层 — 红叉或抖动后重置。  
   公式与对局一致：`startH - 1 <= destH <= startH` 且 `destH + 1 <= 3`。

5. **胜法：俯视恰好五连**  
   顶层恰好五连高亮为胜；可对比六连不触发胜利。

6. **胜法：第三层五枚**  
   ≥5 个己方第三层顶高亮。

7. **胜法：第三层三相邻**  
   己方第三层连通 ≥3 高亮。

实现上：每章用预置「关键帧」局面数组 + `requestAnimationFrame`/`setInterval` 推进；高亮走现有 `render.js` 的 highlights API（若不足则最小扩展，不改对局逻辑）。

## 入口

- 大厅：`index.html` 增加「规则」链接 → `/rules.html`
- 对局界面：状态栏或角落增加「规则」链接 → `/rules.html`
- 规则页：「返回游戏」→ `/`（或带回查询串时回到原 origin）

不要求弹层；独立页即可满足「对局中也能再看」。

## 文件结构

```
public/rules.html    # 页面骨架与七章 DOM
public/rules.js      # 章节时间轴、视口观察、循环控制
public/rules.css     # 章节排版（可并入 style.css，优先独立以免游戏页膨胀）
public/render.js     # 复用绘制（必要时导出/扩展高亮）
shared/board.js      # 复用坐标/邻接
public/index.html    # 加规则入口
public/client.js     # 对局内规则入口（若入口在对局 DOM）
```

静态资源仍由现有 `server.js` 提供；无需新协议。

## 性能与可访问性

- `IntersectionObserver`：仅可见章节的 canvas 在跑动画
- 尊重 `prefers-reduced-motion`：减弱为静态首帧 + 说明文字仍可读
- 移动端：canvas 宽度随容器缩放；章节单列

## 成功标准

- [ ] 大厅与对局均可进入规则页并返回游戏
- [ ] 七章均有循环迷你棋盘演示，观感接近真棋盘
- [ ] 叠层演示与统一公式一致（合法/非法对照清楚）
- [ ] 不可见章节不持续空转动画
- [ ] 纯文字不再是唯一理解规则的方式
